# 触手 · 执行能力

这是神思对话控制的执行技能，不是创作模板。当前页面只是默认上下文，按任务选择实际文档、白板或工坊。只下载、分析或绑定时不擅自生成、迁移旧任务、启同步。

## 入口

完整制作先读 [流程接续](references/workflow-execution.md)：短视频复刻、原创、短剧改编、小说改编分别有入口和确认节点。没有个人 Skill 的新用户也能按公共执行流程与自己的要求制作；不套用作者私人格式，不假称已读取私人规则。

本轮附件或白板已有素材用 import_source 复制为受控会话产物，供后续轮次使用。DOCX剧本用 extract_text 提取正文并保留原件/SHA，再由 read_file 分页读完；不把其中图片或嵌入物冒称已识别。save_text 另存校对记录、标点稿和制作状态；不改原始转写或旧稿。import_file 将TXT/Word等成品导入附件，以返回路径交付。歌曲或动作片段用 clip_media 按真实起止秒裁切，保留源SHA和区间；checkpoint 保存阶段与文件SHA，批准阶段必须经过用户确认。

- `chushou.catalog` 返回真实脚本动作、参数、依赖与宿主替代入口；`chushou.read` 按需读本包说明/脚本。
- `chushou.run` 调用后台白名单执行器，不使用终端命令拼接；`chushou.files/read_file` 回读本会话产物，失败必须报告真实错误，不能把开始执行当作完成。
- `chushou.view_image` 查看抽帧或联系表的真实画面，图片走模型视觉通道，不当作base64文本。先读取分析清单取得fileId及时间，再按需查看；非视觉模型必须明确能力不足，不猜画面。
- `chushou.import_media` 把核验过的下载/抽帧产物放入指定笔记本附件库，然后通过 `board.append_media` 追加原生媒体卡片。读取新白板基线再写；导入成功不代表已绑定、已生成。
- 建卡或修稿前，按[流程接续](references/workflow-execution.md)核对生成卡边界。新卡用 `board.prepare_segments`，已有卡用 `board.bind_references`，支持草稿里的 `{{asset:真实节点ID}}`。在每个应当出现参考的位置插入标记，宿主编译成真实原生引用、逐次序列和偏移；重复引用复用同一节点。只写一份参考清单不算插入。已有卡保留其他配置与旧版本，不需复制新卡。
- 视频按一段能完整演完的剧情建卡。默认规划上限为 30 秒，所选模型或模式上限更低时按实际能力拆分。把对白、动作和紧随其后的反应放在同一卡的分镜内，短尾段先尝试并回前卡或前移分界。把各卡实际总时长写进 `durationSeconds`，核对首末镜时间与卡片读回值；用户指定的短段保留。
- 图片资产也必须保留可编辑的图片生成稿，不能只保存成品或在说明卡写提示词。`board.generate`会保存本次生成稿；导入已生成资产时在`board.append_media`的`drafts[图片节点ID]`一并提供`channel:image`、原完整`prompt`、实际`references`和已知生成参数，无参考明确传`[]`。已有资产用`board.bind_references`补齐原稿；未取得原稿的普通参考图/分析帧不虚构提示词。交付前回读每张资产的图片通道草稿，核对生成栏中的提示词和参考顺序。
- `board.edit` 按已读基线移动/调整卡片、复制、删除及编辑关系线，保留前后历史；删除被引用资产前先解绑。`board.view_media` 通过真实视觉通道验收已生成图片，不能仅根据任务成功宣称画面合格。`board.history` 只读历史；`board.task_action` 停止、放弃或找回本对话原任务，不重发生成。

## 下载与分析

神思中的短视频和网盘分享都通过解析后台解析。缺提取码时由宿主私密输入栏接收，不写入聊天或模型；分享已带码则自动使用。见 [视频与网盘下载](references/video-download.md)。同一神思白板在同一浏览器配置下共用一个即梦画布，图片和视频节点进入该画布，不为每次生成另建画布。

短剧先 `drama_inspect` 核对整剧身份和完整集表，再明确选集或全集运行 `drama_download`。使用 guoapp 2.0.1 的红果模块，短链跳转优先解析整剧 ID；取流空响应会明确失败，不冒称成功、不反复盲试。音乐用 `download_music`，输入歌曲名或歌手，选择结果后下载、校验并导入音频卡片；短视频用 `download_video`，返回真实媒体后 `inspect_video/inspect_motion` 按需抽帧；不能把网页、封面或空文件当视频。详见 [下载规则](references/downloads.md)。

即梦网页画布使用新版官方 `dreamina-canvas`，通过 `webcanvas.canvas` 操作。授权绑定当前浏览器配置，先读取实时模型规格；草稿编辑与积分生成分开。参考使用 Node ID 并回读连线及正文位置，下载真实 Resource ID。详见 [即梦画布 CLI](references/jimeng-canvas-cli.md)。旧 `dreamina` 仅继续已有本地任务，不能用任务查询冒充任意网页画布读取。

已完成下载按文件哈希核对复用，部分失败只恢复失败集；不购买、不搬迁浏览器凭据、不绕过访问控制。网站不再支持、登录或依赖缺失应明确提示，不反复盲试。

未指定识别方式时优先 `transcribe_local`，首次从官方公开源下载固定校验的运行库/模型，之后在本机CPU识别，音轨不上传。详见 [本地识别](references/local-transcription.md)。用户明确指定网站时仍用 transcribe_website，详见 [网站转写](references/website-transcription.md)；网站声称本地识别但不能保证无网络传输。只有用户明确选择并确认云端上传时才用 transcribe_media。三条路线分别记录，不能静默互换。保存真实原文、模型、导出文件和来源；校对与编排看 [校对规则](references/transcript-proofreading.md)。

Windows发行版携带独立Python、下载/图像处理依赖、FFmpeg/ffprobe和Node，不要求用户安装Codex或系统Python。`runtime_check`可离线核验；缺失应修复安装包，不能临时借用作者环境。CLI和会员算力使用同一组神思宿主工具；实际模型仍需支持工具调用和视觉，登录/额度及网站限制不由本地依赖代替。

## 参考与稿件

读取 [原生参考绑定](references/binding.md)。用白板工具直接保存草稿后，回读即可交付。操作栏已经展开时，核对提示词和参考图后单击白板空白处临时收起；下次单击原生成卡即可展开。触手逐卡核对和最终交付都避开底部「关闭」，该按钮会停用这张卡的单击展开。源片、抽帧的溯源关系与实际生成参考独立；未经用户特别指定，源帧不作为生图或视频生成输入。模型限制从当前配置读取，不静默删参考。

正式文档经 documents.write 保存前后历史。白板/插件只为待核对的剧本和具体生成提示词调用 console；普通问答不创建写作编辑器。读取当前选定的已保存全文，不用旧消息或未保存草稿替代。生成仍走原 media/board 工具及其确认、幂等和停止规则。

## 本地个人规则

使用 `skills.list/read` 读取用户配置的本地技能及所引用文件。已有显式 skillRefs 优先；本机创作默认项由本地目录/偏好决定。资产/视频提示词格式、剧本写作规则不随本包分发，未读到个人规则时不能声称已按其执行，也不拿知识库文档冒充已安装 Skill。详见 [宿主与本地规则](references/host-tools.md)。
